# M33.3 shared MT5 recovery primitive proposal

M33-C7 — **bounded recovery of failed components and safely managed
duplicates** — cannot be completed by this Forex repository alone.  Forex owns
the no-order policy, signed recovery request, evidence and listener recovery.
`cs-ai-lab-infra` owns the fixed T480 operation needed to affect MT5 processes.

## Requested fixed operation

The shared owner should provide one hash-bound operation, conceptually
`m33_managed_mt5_recovery_execute`.  It must take no caller-supplied command,
path, process identifier, account or credential.  It may consume only the
current Forex recovery request and immutable local runtime binding.

Before an effect it must hold the same `Global\\Forex-M33-Trading-Health-Recovery`
mutex and recheck all of the following:

- maintenance hold remains enabled and Forex intent remains `RUN_DEMO`;
- request ID, generation, boot, release, configuration, account and profile
  bindings are current and unexpired;
- the configured terminal executable is the exact Session 0 client;
- no unattributable `terminal.exe`/`terminal64.exe` process exists;
- the account is GOMarketsMU-Demo/AUD/EURUSD, with zero positions, zero pending
  orders and no unresolved execution or monitoring work.

It may start MT5 only when there are zero managed clients.  It may recycle
managed duplicates only after the same flat/no-pending/no-unresolved checks,
and must never terminate another process.  Any unknown process, stale proof,
lock failure, task failure or incomplete reconciliation must preserve the hold,
publish `INTERVENTION_REQUIRED`, and make no further retry.

Its fixed receipt must bind request identity, inventory before/after, exact
action, timestamps, payload/configuration hashes, post-action account and
monitor observations, and `broker_mutation: NONE`.  It must provide no order,
cancel, close, risk, credential, or account-setting operation.

## Boundary

Until the shared owner independently designs, reviews, releases and proves this
operation, the Forex listener executor continues to refuse MT5 and duplicate
client actions.  Listener-only held recovery may be reviewed separately, but
must not be represented as completion of M33-C7.
