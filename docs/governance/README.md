# Governance implementation workstream

This directory holds concise, durable role guidance for repository development.
It is deliberately **ancillary** to the Forex capability roadmap in
`milestone_registry.json`.

The Forex capability milestones (`M0`–`M32`) remain the sole authority for
trading/research capability scope, evidence, human sign-off, and `PROVEN`
completion. This workstream does not create a second completion system and
does not change the status of an `M` milestone.

The Builder and Reviewer guides reinforce `AGENTS.md`,
`docs/evidence_and_milestones.md`, and `docs/triad_review.md`; they do not
replace them or add a second workflow state machine.
