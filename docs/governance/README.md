# Governance implementation workstream

This directory holds the human-authorised plan for improving the repository's
development workflow. It is deliberately **ancillary** to the Forex
capability roadmap in `milestone_registry.json`.

The Forex capability milestones (`M0`–`M32`) remain the sole authority for
trading/research capability scope, evidence, human sign-off, and `PROVEN`
completion. This workstream does not create a second completion system and
does not change the status of an `M` milestone.

The planned work packages, their boundaries, dependencies, and acceptance
conditions are in [implementation_workstream.md](implementation_workstream.md).
They may be started only after explicit human authorisation. Until then, every
package is a proposal, not an implementation claim.

The eventual Builder and Reviewer role guides will live here. They must
reinforce `AGENTS.md`, `docs/evidence_and_milestones.md`, and
`docs/triad_review.md`; they must not replace them.
