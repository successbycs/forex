# M20.14 — agentic macro/event shadow trial

## Status and purpose

**Planned only — do not execute.** This is a small observational extension to
the EURUSD/M1 Demo workflow. It evaluates whether bounded macro and sentiment
context would have advised waiting on an already-valid deterministic candidate.
It does not change the current listener, MT5 execution path, risk plan, or
Demo authority.

## Fixed boundary

```text
deterministic eligible M1 candidate
  -> deterministic cost/risk/SL/TP gates
  -> read-only analyst context and structured advice
  -> deterministic shadow fusion result
  -> persist comparison only; existing execution remains unchanged
```

There is no agent call capable of creating a candidate, reversing its side,
changing lots, entry, SL, TP, holding time, strategy ownership, broker state,
or an open position. No candidate means no agent-originated trade.

## Minimal design

| Component | Responsibility |
| --- | --- |
| `AgentContextBuilder` | Creates a versioned, timestamp-bounded context from the candidate, M1/M5/H1 observations, cost gates, and read-only macro/event sources. |
| `ForexAnalystAgent` | Returns constrained analytical advice only. It has no MT5, execution, or arbitrary-write tool. |
| `AnalystDecision` | Typed result: `NEUTRAL`, `CAUTION`, `WAIT`, `VETO`, or `AGENT_UNAVAILABLE`, with confidence, reason codes, sources, freshness, expiry, and version hashes. |
| `SignalFusionEngine` | Deterministically records `would_allow`, `would_wait`, or `would_veto`; in this package it cannot alter execution. |
| Immutable audit records | Link the candidate, source snapshots, versions, decision, shadow fusion result, and eventual broker outcome. |

The initial analytical focus is scheduled EUR/USD macro-event risk, not an
LLM claim to predict M1 direction. Known high-impact EUR/USD events should be
represented by fixed deterministic blackout windows. The agent may classify
and explain residual context only.

## Required evidence model

The unit of analysis is one eligible deterministic candidate at a known
timestamp. Persist the candidate/strategy/regime, M1/M5/H1 snapshot hashes,
source payload or immutable reference, publication/event and retrieval times,
prompt/model/tool/fusion/configuration versions, schema validity, decision
expiry, and later broker lifecycle/net P&L where a trade actually occurred.

No source later than the candidate timestamp may enter its context. Missing,
stale, conflicting, malformed, or untraceable context is `AGENT_UNAVAILABLE`,
not `NEUTRAL`.

## Evaluation

Compare deterministic outcomes and shadow advice by strategy, regime,
direction, session, event proximity, spread, exit reason, and net P&L after
costs. Predeclare measures: candidate count, wait/veto rate, realised net P&L,
win rate, average win/loss, drawdown, false-veto rate, and harmful-allow rate.
Broker-verified P&L exists only for trades actually executed; counterfactual
results require a separately declared deterministic exit simulation.

## Later decision gate

Only after a defined Demo sample and review may a separate approved package
consider permitting one narrow, high-confidence, fresh `WAIT/VETO` influence
for one strategy. Agent-created, reversed, resized, or risk-modified orders
remain out of scope.
