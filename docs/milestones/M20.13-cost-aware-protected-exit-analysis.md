# M20.13 — cost-aware protected-exit analysis

## Status and purpose

Operator amendment, 2026-09-10: the latest instruction to resolve the broker
blockers using other sources authorises the temporary W1 intraday cost policy
described in `Research/2026-09-10-w1-broker-blocker-resolution.md`. Only this
entry safeguard and estimated cost allowance are implemented; the broader
protected-exit analysis below remains planned. Existing position exits are
unchanged.

**Planned only — do not execute.** This package defines the analysis needed to
improve the clarity and economic viability of M1 trade plans while preserving
the current deterministic strategy ownership model.

## The practical issue

A SELL opened at `1.16271` with SL `1.16288` and TP `1.16236` risks 1.7 pips
to pursue 3.5 pips: approximately 2:1 gross reward-to-risk. The direction is
correct for a SELL—profit occurs when it is bought back lower—but gross reward
alone does not establish that the trade is worthwhile after spread, commission,
swap, and slippage.

## Proposed analysis and future delivery rules

| Area | Required analysis / future rule |
| --- | --- |
| Cost-aware entry | Estimate round-trip spread, commission, swap where relevant, and slippage before submission. Reject when projected net at TP is below the configured minimum net-profit floor. |
| Spread-aware SELL/BUY plans | Use executable quote sides: BUY opens at ask and closes at bid; SELL opens at bid and closes at ask. Require the target to clear this spread effect. |
| Strategy-owned SL/TP | Set stops from the owner strategy's current closed-candle structure/volatility: for a SELL, beyond the relevant swing high; for a BUY, beyond the relevant swing low. Targets must satisfy the strategy's declared reward/risk rule and the cost gate. |
| Correct directional validation | BUY requires `SL < entry < TP`; SELL requires `TP < entry < SL`. Reject malformed plans before attempting MT5. |
| Expected-versus-actual record | Retain proposed and filled entry, SL, TP, estimated and actual costs, gross/net AUD P&L, strategy/regime, rationale, and exit type: TP, SL, time stop, reversal, or broker-side closure. |
| Attribution | Only the strategy that created the position may amend or close it, except universal operational protection. Counter-signals remain context. |

## Questions to answer before any rule change

1. What is the observed distribution of realised round-trip costs by strategy,
   session, side, and spread band?
2. How often does each target clear the configured net-profit floor at entry,
   and how often does the realised outcome differ materially from the estimate?
3. Are SL distances and target distances structurally sensible for the
   selected regime, or are time/reversal exits dominating them?
4. Does any proposed minimum-net threshold reduce trade count so much that the
   M1 strategy has insufficient viable candidates?

Any later implementation must remain Demo-only, deterministic, versioned, and
subject to fresh M20 evidence. It must not use an agent or unrelated strategy
signal to modify an existing position.
