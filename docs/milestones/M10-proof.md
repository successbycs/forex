# M10 — free official release calendar

M10 uses only the FRED CPI release-date endpoint and the ECB public statistical
calendar. US FRED events are labelled `DATE_ONLY`: they are source-published
release dates, not a FRED availability timestamp. ECB entries are labelled
`CET_SCHEDULED_TIME` when the public calendar provides that value. No forecast,
consensus, actual, revision, cancellation or intraday availability claim is
made. Those require a separately approved commercial source.
