# Goal prompts

This directory retains the human-approved Goal Mode prompts used to execute
milestones. A goal prompt is an execution brief, not evidence of completion;
the milestone registry remains the declarative contract and `project_state`
remains the mutable execution record.

| Prompt | Purpose |
| --- | --- |
| [M2 shared T480 PostgreSQL](M2-shared-t480-postgres-goal.md) | Complete M2 using the shared T480 AI Lab PostgreSQL service. |

Keep prompts versioned with the related architecture decision. Never put
credentials, account details, database passwords, or broker secrets in them.
