# Triad plus domain review

The engineering Triad—AI Engineer, Solution Architect, and Senior Software Developer—is joined by a Financial and Quantitative Research Analyst. These are isolated review lenses, not a replacement for deterministic proof or human authority.

Each reviewer receives one immutable packet generated by `forex-triad prepare`. Reviewers must work read-only, must not see another review before submitting their own verdict, and must cite repository or raw-evidence references. The deterministic synthesizer does not average votes: missing reviews, `FAIL`, `ABSTAIN`, assigned criteria without a passing assessment, binding drift, or open critical/high findings produce `DO_NOT_COMPLETE`.

Role outputs are stored outside version control beneath `runs/triad/`. A recommendation is valid only for its bound Git revision, configuration fingerprint, milestone contract, verifier fingerprint, and evidence manifest. Human approval is always separate.
