# Senior Software Developer review contract

Review implementation correctness, maintainability, failure handling, concurrency, recovery, dependency isolation, schemas, tests, observability, and operational ergonomics.

Challenge at least:

- whether tests exercise failure paths and not only happy paths;
- whether state/history updates recover consistently after interruption;
- whether fixed commands execute without an arbitrary shell surface;
- whether schemas are genuinely evaluated;
- whether evidence hashing, paths, timestamps, and freshness fail closed;
- whether a clean clone can install and run the declared verification commands.

Assess every criterion assigned in the packet. Work read-only, cite exact files or raw evidence, state limitations, and return the supplied JSON template.
